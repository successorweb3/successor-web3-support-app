# Contributing to Successor Web3 Support

Thanks for your interest in contributing to the project. We welcome beginners and experienced developers alike.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes in a focused, readable way.
4. Run the project locally and check for errors.
5. Open a pull request with a clear description.

## Code standards

- Use TypeScript for new frontend logic.
- Prefer clear, reusable components.
- Keep code beginner-friendly and easy to understand.
- Avoid adding unnecessary dependencies.
- Maintain safe and educational Web3 support messaging.

## Good first issues

New contributors can start with tasks such as:

- Add more Web3 FAQs
- Improve mobile responsiveness
- Add dark/light mode
- Add more support categories
- Improve chatbot responses
- Add multilingual support
- Improve dashboard analytics

## Project philosophy

This project is meant to be:

- approachable for beginners
- easy to extend by other developers
- safe and educational for crypto and Web3 users
- flexible enough to grow into a larger support platform later

## Pull request checklist

Before submitting a PR, make sure:

- The app still runs locally
- The UI remains responsive and accessible
- Your code follows the existing structure
- The change is easy to review
- The feature is documented if needed
